# Architecture Decision Records (ADRs)

Cada decisión de agregar una tecnología o mecanismo se documenta acá **antes** del commit/tag correspondiente.

Formato sugerido por entrada:

```
## ADR-000: <título>
Fecha:
Milestone:
Contexto (¿qué limitación observamos?):
Alternativas consideradas:
Decisión:
Costo que introduce:
Métrica con la que evaluaremos si valió la pena:
```
